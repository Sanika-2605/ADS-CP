Architecture

Project Structure

Modular C codebase with clean separation of data structures and business logic.

📊

transaction.c / .h

Trie for vendor→category mapping, Segment Tree for daily expense range queries.

📈

portfolio.c / .h

Red-Black Tree for balanced stock storage, Max Heap for top gainer extraction.

🧾

bills.c / .h

Min Heap priority queue — earliest due bill always at root.

🏛️

tax.c / .h

Bracketed slab calculation with DP memoization by income buckets.
